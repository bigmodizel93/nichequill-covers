# BNBHubs — ONE OF ONE Wallpaper Pack (Galaxy Z Fold 7)

One-of-one wallpapers in the BNBHubs Red Sea coastal palette, sized natively for
**both screen states** of the Galaxy Z Fold 7:

- 📂 `inner-unfolded/` — **1968 × 2184** (the big screen when open)
- 📂 `cover-folded/` — **1080 × 2520** (the outer screen when closed)

Each folder has all **5 skins** in **dark** + **light**. Use the file that
matches the screen you're setting — that's what prevents the "can't apply / bad
crop" error (the two screens are completely different shapes).

## Apply on the Fold 7
**Unfolded (inner):** open the phone → long-press home → Wallpaper and style →
Change wallpaper → Gallery → pick from `inner-unfolded` → set, **don't zoom**.
**Folded (cover):** Settings → Wallpaper and style → **Cover screen** → Gallery
→ pick the matching skin from `cover-folded` → set.
Match dark/light file to your system theme.

`generate.py` (Pillow + numpy) renders both screen sizes; `OWNER`/`INITIAL` at
the top drive the fingerprint, so the art is uniquely tied to the name.
